# Statistical Computing Practicals

Ten Python practicals organized in the order of the supplied Statistics Lab manual-1_organized.pdf. Each folder contains its aim, runnable source and verified output. Each practical is added in a separate commit.

## Setup

Use Python 3.12 and pip. The five required packages are **numpy, pandas, scipy, matplotlib and statsmodels**. Their tested versions are pinned in [requirements.txt](requirements.txt).

From the repository root in Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe practical_01_student_scores/main.py
```

See [DEPENDENCIES.md](DEPENDENCIES.md) for the PDF's imports, each practical's requirements, macOS/Linux installation, and commands to check the environment. If you activate the virtual environment, you can use `python` for the run commands in each practical's README.

## Notes about the source

- Original datasets and statistical methods are retained. PDF line wrapping and indentation are repaired. Plots support `--save`, and Practical 6 prints its simulation summary.
- Practical 7 contains duplicated code and no weight dataset in the manual. Its corrected script accepts observations; the checked-in example is explicitly illustrative. See its README.
- Console outputs are generated by running the scripts, rather than copying potentially inconsistent values from the PDF. See [VALIDATION.md](VALIDATION.md) for differences.
- The pre-existing root file `5` is retained.
